Samhita's Online Wedding Hall Booking Management System

This project is designed to make wedding hall booking simple and convenient.

Customers can view wedding hall details and manage their bookings and payments through this website.

Project Features

  • Customer Management
  • Wedding Hall Management
  • Booking Management
  • Payment Management
  • Insert Records
  • View Records
  • Update Records
  • Delete Records

Technologies Used

  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Express.js
  • MySQL Workbench

Project Objective

The main objective of this project is to manage wedding halls, customers, bookings and payments efficiently using an online system.
